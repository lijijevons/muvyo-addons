# lijijevons 的 Muvyo 搜索插件

在 Muvyo「插件 → 第三方插件 → 插件仓库」中添加：

```text
https://github.com/lijijevons/muvyo-addons
```

添加一次仓库，即可分别安装、配置和启用以下两个搜索源。

| 插件 | 版本 | 使用方式 |
| --- | --- | --- |
| 迷你影视搜索 | 1.1.1 | 匿名搜索；获取受限链接时使用用户自己的邮箱密码自动登录，设置页可验证登录状态 |
| 不太灵搜索 | 1.0.0 | 默认匿名网盘搜索，直接返回分享链接；磁力需登录令牌及网站已有会员权限 |

不太灵网页登录含图形验证码，需在网站正常登录后使用令牌，插件不自动处理验证码或购买会员。
两种来源的结果都标明具体网盘或磁力类型，仅返回 Muvyo 搜索协议支持的资源类型。

每位用户在自己的 Muvyo 中填写自己的凭据；仓库没有预置账号、密码或登录 Cookie。
安装前请查看插件要求访问的域名。详细配置与限制见各插件目录中的 README。

这是独立作者提供的第三方插件，与 Muvyo 及来源网站没有官方合作关系。
仅使用有权访问的资源，并遵守来源网站和 Muvyo 的使用约定。

## 更新

插件更新后，在 Muvyo 的插件仓库检查更新并确认安装。
本仓库仅发布加密签名插件和签名索引，不包含明文源码或签名私钥。

## 验证范围

- 两个插件共 31 项本地测试通过，插件签名及仓库索引签名均已验证。
- 迷你影视 1.1.1 已由作者实测可用。
- 不太灵公开网盘搜索已通过真实接口测试；会员磁力尚未用真实会员账号验证。
