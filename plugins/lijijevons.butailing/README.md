# 不太灵搜索

插件 ID：`lijijevons.butailing`，作者 `lijijevons`。

默认搜索公开网盘资源，返回真实分享链接，可直接复制或转存；首个标签显示具体网盘名称。
支持 Muvyo 接收的百度、阿里、123、115、天翼、光鸭，以及磁力链接。
不返回 Muvyo 搜索协议不支持的夸克、迅雷、UC 等类型。

磁力搜索需要网站已有会员权限和有效登录令牌。网页登录含图形验证码，请在浏览器正常完成。
打开开发者工具 Network，查看不太灵的 API 请求，将请求头 `Authorization` 中 `Bearer ` 后的值
填入插件设置的「不太灵登录令牌」。配置为保密字段，不要发给别人或提交到仓库。
插件只向 `www.butai0.club` 发送该令牌，不自动购买会员或处理验证码。

在「资源范围」选网盘、磁力或两者。最多搜索 3 页，每次最多返回 100 条，不保证穷尽全部结果。
按年份或类型搜索时，利用前 24 个匹配作品的元数据进行核对，未核对上的候选会跳过。
多来源部分失败时保留成功结果并标记部分失败；仅磁力失败时明确提示登录或会员限制。
不声明 TMDB 精确匹配、完结剧集模式及原文链接解析。

公开网盘接口已实测，磁力会员接口尚未使用真实会员账号验证。仅使用有权访问的资源。
