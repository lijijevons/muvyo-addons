# 迷你影视搜索

作者 lijijevons，插件 ID `lijijevons.miniyingshi`。

1.1.1：修复认证 POST 缺少 Origin 和站点访问会话初始化步骤导致的 403。
设置页新增账号区，通过站点 `/auth/me` 验证登录是否真的成功；可点刷新检查。
支持邮箱和保密密码，获取受限链接时自动登录并缓存 Cookie，失效时尝试刷新或重新登录。
搜索始终匿名请求，失效 Cookie 不影响列表；取链接先匿名尝试，仅站点要求登录时使用登录凭据。
搜索结果第一个标签显示「磁力」「百度网盘」「115网盘」等具体资源类型，获取链接前即可区分。

支持关键词搜索磁力，以及百度、阿里、123、115、天翼和光鸭网盘分享。
只列出 Muvyo 搜索协议支持的资源类型。暂不返回夸克、迅雷、UC、PikPak 分享。

搜索列表无需登录，也不会发送配置中的 Cookie。获取链接先匿名尝试；
若站点要求登录，可在插件设置填写「迷你影视登录邮箱」和「迷你影视登录密码」。
首次需要登录时才提交账号密码；缓存 Cookie 并跨调用复用，失效时先刷新，刷新失效再登录。
修改邮箱或密码后不会复用旧会话，清除插件数据可以移除缓存登录态。
密码错误后至少等待一分钟再用相同凭据尝试，避免反复登录；修改凭据后可立即重试。
站点限流、网络失败或需要额外验证时会停止自动重试，需到网站检查。

若不使用账号密码，也可单独填写备用 Cookie；账号密码完整填写时优先使用自动登录。
在浏览器登录 https://www.miniyingshi.com/ ，打开开发者工具的 Network，
执行一次搜索，复制该站点请求的 Cookie 请求头值，填入插件的保密配置项。
Cookie 属于登录凭据，请仅保存在本机和插件设置里，不要提交到仓库或发给他人。
账号密码仅向迷你影视的 `/api/auth/login` 提交，不写入插件日志或额外存储；
插件持久存储只保留会话 Cookie 和凭据摘要。不会自动注册账号或绕过站点验证。

选中资源后才获取链接，来源返回限流、失效或需要验证时会提示原因。
不支持 TMDB 编号精确搜索、空关键词搜索、完结剧集模式及磁力合集展开。
年份、类型与已知季号用于缩小候选；网盘跨作品合集不标记为单季。
搜索最多读取前 5 个匹配作品的网盘列表、前 3 页磁力，最多返回 100 条。
同时搜索两类来源时交替展示；不是全站穷尽搜索。

仅使用有权访问的资源，并遵守来源站点与 Muvyo 的使用约定。
